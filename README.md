# task-tracker-java
A simple task tracker cli made in java, for gaining practical knowledge about Object Oriented Programming approach as well as Java programming language as a whole.

##### What I Learned:

- File Handling I/O
- Basic implementation of OOP.


### Features:

[type in "help" for help]

- [x] Saves tasks and loads task from a CSV file.
- [x] Timestamp for Created and Updated Date and Time
- [x] Handles ID accurately for tasks imported from tasks as well as the recently added ones.
