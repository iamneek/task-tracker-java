# task-tracker-java
A simple task tracker cli made in java, for gaining practical knowledge about Object Oriented Programming approach as well as Java programming language as a whole.

##### Learnings:

- File Handling I/O
- Basic implementation of OOP.


### Features:

[type in "help" for help]

- [x] Saves tasks and loads task from a CSV file.
- [x] Timestamp for Created and Updated Date and Time
- [x] Handles ID accurately for tasks imported from tasks as well as the recently added ones.

---

#### Help Menu:

Add item to List -> add Bring something
Delete item from List -> delete <task_id>
Update items in List -> update <task_id> Bring nothing.
Change task status -> mark <task_id> <options> [options: todo, in-progress, done]

List all items -> list
List items with todo status -> list todo
List items with in-progress status -> list in-progress
List completed tasks -> list done

Exit Program -> exit
To bring up this menu -> help
